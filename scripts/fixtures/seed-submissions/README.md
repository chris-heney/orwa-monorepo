# Seed submission fixtures

Tiny valid binaries used by `scripts/seed-scholarship-awards.ts`:

- `minimal.pdf` — one-page PDF (transcripts, letters, essays, bios, supporting docs)
- `minimal.png` / `minimal.jpg` — 1×1 images (photographs)

Regenerate with the seed script’s companion generator or leave as-is. Do not replace with large real documents.
